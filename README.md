# Echo — сборка APK прямо с телефона (без ПК)

Сборка происходит в облаке GitHub Actions. С твоей стороны — только браузер на телефоне.

## Шаги

1. Открой github.com в браузере телефона, зарегистрируйся (бесплатно), если ещё нет аккаунта.
2. Нажми **+** (вверху) → **New repository**. Назови как хочешь (например `echo-app`), сделай **Public**, создай.
3. В новом репозитории: **Add file → Upload files**.
4. Загрузи ВСЕ файлы и папки из этого архива, сохраняя структуру:
   - `www/index.html`
   - `package.json`
   - `capacitor.config.json`
   - `.github/workflows/build.yml`
   (папку `.github` браузер обычно позволяет перетащить целиком — если нет, создавай файлы через "Add file → Create new file" и вручную пиши путь `.github/workflows/build.yml`)
5. Нажми **Commit changes**.
6. Перейди во вкладку **Actions** репозитория. GitHub сам увидит workflow и начнёт сборку (или нажми **Run workflow**, если не запустилось само).
7. Подожди 3-5 минут. Когда сборка позеленеет (значок ✓) — открой её и внизу в разделе **Artifacts** будет `echo-debug-apk` — жми, скачается `.apk` прямо на телефон.
8. Открой скачанный файл на телефоне (может попросить разрешить установку из непроверенных источников — это нормально для debug-сборки) — приложение установится.

## Важно про API-ключ
Внутри приложения (⚙️ Настройки) нужно вписать свой Anthropic API-ключ
(получить на https://console.anthropic.com → API Keys, тоже можно с телефона).
Ключ хранится только локально на телефоне.

## Если сборка упадёт с ошибкой
Открой Actions → упавший запуск → посмотри лог, обычно там прямо написано что не так
(чаще всего — опечатка в пути файла при загрузке). Можно скинуть мне текст ошибки.
